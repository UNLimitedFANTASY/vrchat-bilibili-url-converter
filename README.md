# VRChat 哔哩哔哩视频链接转换工具

一个面向 **VRChat 视频播放器使用场景** 的 Windows 链接转换小工具。

当你在 VRChat 世界中使用支持外部视频 URL 的播放器时，部分哔哩哔哩链接可能需要先通过指定的解析/播放器地址进行拼接后再使用。本工具可以将哔哩哔哩网址自动转换为指定格式，并自动复制结果，减少反复手工拼接链接的操作。

默认转换前缀为：

```text
https://biliplayer.91vrchat.com/player/?url=
```

例如：

```text
原始网址：
https://www.bilibili.com/video/BVxxxxxxxxxx

转换后：
https://biliplayer.91vrchat.com/player/?url=https://www.bilibili.com/video/BVxxxxxxxxxx
```

> 本项目主要用于 VRChat 视频播放器中的链接输入场景。实际能否播放取决于具体 VRChat 世界所使用的视频播放器、URL 解析服务、网络环境以及目标视频本身。

## 主要功能

- 面向 VRChat 视频播放器使用场景快速转换哔哩哔哩链接
- 手动粘贴网址并一键生成新的播放器链接
- 生成完成后自动复制到 Windows 剪贴板
- 长网址在文本框内部水平滚动显示，避免文字溢出、重影或覆盖相邻控件
- 支持多显示器窗口定位：关闭确认和前缀设置窗口会跟随主窗口所在显示器并居中显示
- 支持高 DPI / 高分辨率缩放，窗口、字体、文本框、按钮和间距会按显示器缩放比例自动调整
- 主窗口跨不同缩放比例的显示器移动时，会根据新的 DPI 自动重新布局
- 自动监听剪贴板中的哔哩哔哩链接
- 支持识别：
  - `bilibili.com`
  - `b23.tv`
  - `bilibili.tv`
- 检测到符合条件的链接后自动恢复窗口并完成转换
- 支持自定义网址生成前缀
- 前缀修改必须通过独立设置窗口完成，降低误操作风险
- 剪贴板监听可在主界面和系统托盘右键菜单中自由开启或关闭
- 支持最小化到系统托盘
- 支持关闭窗口时选择：
  - 最小化到托盘
  - 彻底退出
  - 取消
- 支持记住关闭行为
- 所有配置保存在程序目录下的 `BiliUrlConverter.ini`
- 支持单实例运行，防止程序重复开启
- 已有实例运行时再次启动程序会直接恢复原窗口
- 支持启动后自动隐藏到系统托盘
- 启动隐藏功能可在主界面或托盘右键菜单中自由开启或关闭
- 启动隐藏设置会保存到便携式 `BiliUrlConverter.ini`
- 不使用注册表保存配置
- 原生 Win32 实现
- 提供 x86 与 x64 两种 Windows 构建

## 适用场景

典型使用流程：

1. 在浏览器、聊天软件或其他位置复制哔哩哔哩视频链接。
2. 程序监听到符合条件的网址。
3. 自动生成适合当前配置前缀的转换链接。
4. 转换结果自动复制到剪贴板。
5. 回到 VRChat。
6. 将转换后的链接粘贴到世界中的视频播放器 URL 输入框。

这样可以减少：

```text
复制 Bilibili 地址
→ 手工输入解析地址
→ 再拼接视频地址
→ 再复制
→ 回到 VRChat 粘贴
```

这一整套重复操作。

## 默认转换规则

默认前缀：

```text
https://biliplayer.91vrchat.com/player/?url=
```

转换逻辑：

```text
生成网址 = 自定义前缀 + 原始哔哩哔哩网址
```

本工具并不把前缀写死。你可以点击程序中的 **“修改网址前缀”**，在独立设置窗口中更换为其他兼容服务的地址。

修改后的前缀会保存到本地配置文件，下次启动程序时继续使用。

## 使用方法

### 手动转换

1. 启动程序。
2. 将哔哩哔哩视频网址粘贴到“原始网址”输入框。
3. 点击“生成并复制”。
4. 程序生成新的网址。
5. 转换结果自动进入剪贴板。
6. 回到 VRChat，将链接粘贴到视频播放器中。

### 自动监听

开启：

```text
自动监听剪贴板中的哔哩哔哩网址
```

后，只需要复制受支持的哔哩哔哩链接。

程序会自动：

```text
识别链接
→ 生成转换网址
→ 复制结果
```

程序最小化到系统托盘后仍可以继续监听。

## 自定义网址前缀

为了避免误操作，前缀不能直接在主界面修改。

需要点击：

```text
修改网址前缀
```

然后在独立设置窗口中编辑。

默认值：

```text
https://biliplayer.91vrchat.com/player/?url=
```

如果你使用其他适用于 VRChat 视频播放器的解析/播放器服务，也可以替换成对应的 URL 前缀。

## 便携配置

本程序不使用 Windows 注册表保存用户设置。

配置文件位于 EXE 同一目录：

```text
BiliUrlConverter.ini
```

主要保存：

```ini
[Settings]
Prefix=https://biliplayer.91vrchat.com/player/?url=
Monitor=1
CloseAction=0
StartHidden=0
```

其中：

- `Prefix`：网址生成前缀
- `Monitor`：剪贴板监听开关
- `CloseAction`：窗口关闭行为
- `StartHidden=0`：程序启动后正常显示主窗口
- `StartHidden=1`：程序启动后直接隐藏到系统托盘

如需恢复默认配置：

1. 完全退出程序。
2. 删除 `BiliUrlConverter.ini`。
3. 重新启动程序。

## 系统托盘

程序支持最小化到 Windows 系统托盘。

托盘右键菜单可以：

- 显示主窗口
- 开启 / 关闭剪贴板监听
- 修改网址前缀
- 恢复“关闭时再次询问”
- 退出程序

适合在进入 VRChat 前启动，然后长期最小化运行。

## 隐私说明

剪贴板监听和网址识别均在本地完成。

程序只读取 Windows 剪贴板中的文本，用于判断是否包含受支持的网址。

本程序自身不包含：

- 用户账号登录
- 数据上传
- 云端同步
- 遥测统计
- 注册表配置保存

如果不需要自动识别功能，可以随时关闭剪贴板监听。

- Electron
- Python GUI
- Go Runtime
- OLE / COM 初始化
