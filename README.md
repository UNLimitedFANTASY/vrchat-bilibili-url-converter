# VRChat 哔哩哔哩视频链接转换工具

一个面向 **VRChat 视频播放器使用场景** 的 Windows 链接转换小工具。

本工具可以识别哔哩哔哩相关网址，将原始视频链接拼接到可配置的网址前缀后，自动生成新的播放链接，并支持自动复制、剪贴板监听、系统托盘、单实例运行、启动后隐藏到托盘等功能。

> 当前版本：**v1.2.0**

---

## 主要功能

- 手动输入或粘贴哔哩哔哩视频网址并生成转换链接
- 自动复制生成后的链接到 Windows 剪贴板
- 支持剪贴板监听，复制哔哩哔哩网址后可自动识别并转换
- 支持 `bilibili.com`、其子域名、`b23.tv`、`bilibili.tv`
- 支持自定义网址前缀
- 自定义前缀通过独立设置窗口修改，避免误操作
- 支持系统托盘
- 支持记住关闭窗口时的处理方式
- 支持单实例运行，禁止程序重复开启
- 已有实例运行时再次启动 EXE，可直接恢复原窗口
- 支持“启动后自动隐藏到系统托盘”
- 启动隐藏功能可在主界面或托盘右键菜单中开启/关闭
- 支持便携式 INI 配置，不依赖注册表
- 支持多显示器环境下弹窗跟随主窗口
- 支持 Per-Monitor DPI，高分辨率和不同缩放比例显示器下自动适配
- 优化长网址显示，避免字符堆叠、重影和控件覆盖

---

## 适用场景

本项目主要用于 **VRChat 世界中的视频播放器 URL 输入场景**。

典型流程：

```text
复制哔哩哔哩视频网址
↓
程序自动识别
↓
生成转换后的链接
↓
自动复制
↓
返回 VRChat
↓
粘贴到视频播放器的 URL 输入框
```

本工具只负责在 Windows 本地完成：

- 网址识别
- 字符串拼接
- 剪贴板读取 / 写入
- 本地配置保存
- 托盘驻留

它本身**不提供视频解析服务器，也不在本地运行视频解析服务**。

---

## 默认转换规则

当前默认网址前缀：

```text
https://biliplayer.91vrchat.com/player/?url=
```

例如原始网址：

```text
https://www.bilibili.com/video/BVxxxxxxxxxx
```

生成：

```text
https://biliplayer.91vrchat.com/player/?url=https://www.bilibili.com/video/BVxxxxxxxxxx
```

网址前缀可以在程序中自行修改，因此本工具并不强制依赖某一个固定服务地址。

## 使用方法

### 手动转换

1. 启动程序。
2. 在“原始网址”文本框粘贴哔哩哔哩网址。
3. 点击生成 / 复制按钮。
4. 程序生成新链接并自动复制到剪贴板。
5. 返回 VRChat。
6. 将链接粘贴到世界中的视频播放器 URL 输入框。

### 剪贴板自动监听

开启剪贴板监听后：

1. 在浏览器或其他程序中复制哔哩哔哩网址。
2. 本工具识别剪贴板中的网址。
3. 自动生成转换后的链接。
4. 自动将结果复制回剪贴板。

程序会忽略自己刚生成的内容，避免重复触发转换。

## 启动后自动隐藏到托盘

v1.2.0 新增：

```text
启动后自动隐藏到系统托盘
```

开启后，下次运行程序时：

- 不显示主界面
- 直接进入 Windows 系统托盘
- 剪贴板监听功能仍然可以正常工作

可以通过：

- 主界面开关
- 系统托盘右键菜单

开启或关闭这一功能。

对应配置：

```ini
StartHidden=0
```

表示正常显示主窗口。

```ini
StartHidden=1
```

表示启动后直接隐藏到系统托盘。

## 单实例运行

v1.2.0 开始，程序禁止多开。

如果程序已经运行，再次双击 EXE：

- 不会产生第二个程序实例
- 不会出现多个托盘图标
- 不会产生多个剪贴板监听器
- 如果已有程序隐藏在托盘，会恢复已有主窗口

因此再次运行 EXE 也可以作为快速唤醒程序的一种方式。

## 自定义网址前缀

点击程序中的“修改网址前缀”进入独立设置窗口。

修改后点击：

```text
保存并应用
```

即可生效。

程序也提供恢复默认前缀功能。

自定义前缀会保存在本地 INI 文件中。

## 便携配置

程序不使用 Windows 注册表保存用户设置。

配置文件位于 EXE 同目录：

```text
BiliUrlConverter.ini
```

主要配置包括：

```ini
[Settings]
Prefix=https://biliplayer.91vrchat.com/player/?url=
Monitor=1
CloseAction=0
StartHidden=0
```

不同版本中具体字段可能略有调整。

从 v1.1.2 升级到 v1.2.0 时，可以直接保留原来的 `BiliUrlConverter.ini`，无需重新设置。

如果需要恢复默认配置：

1. 完全退出程序；
2. 删除 `BiliUrlConverter.ini`；
3. 再次启动程序。

- 开启 / 关闭剪贴板监听
- 开启 / 关闭启动后自动隐藏到托盘
- 修改网址前缀
- 恢复关闭提示
- 退出程序

---

## 高 DPI 与多显示器

程序支持 Windows 高 DPI 和多显示器环境。

包括：

- 100%
- 125%
- 150%
- 175%
- 200%

等常见 Windows 显示缩放比例。

窗口在不同缩放比例的显示器之间移动时，会重新计算字体、窗口和控件尺寸。

关闭确认窗口和网址前缀设置窗口会跟随主窗口所在显示器，并以当前主窗口为基准进行定位。
